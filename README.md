# Chitra personal site

A deliberately bare-bones personal website. It has no CSS, JavaScript, frameworks, or build step.

## Deploy with GitHub Pages

1. Create a public GitHub repository.
2. Commit and push this folder's contents, keeping `index.html` at the repository root.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Once GitHub provides the Pages URL, add `chitrasingh.me` as the custom domain in the same settings page. GitHub will show the DNS records needed in GoDaddy.

Before publishing, replace the `#` in the application-form link with the real form URL.
